Questão 1

Qual tipo de variável é utilizado para armazenar textos?

✅ Gabarito: C) string

Comentário do Professor

A variável do tipo string é utilizada para armazenar palavras, frases e qualquer conjunto de caracteres.

nome = "Maria" cidade = "Petrópolis"

Analisando as alternativas

  • ❌ int → armazena números inteiros.
  • ❌ float → armazena números decimais.
  • ✅ string → armazena textos.
  • ❌ boolean → verdadeiro ou falso.

Questão 2

Qual será o resultado?

idade = 20 print(idade)

✅ Gabarito: B) 20

A variável recebeu o valor inteiro 20. Quando usamos print(idade), o Python exibe exatamente o valor armazenado.

Resultado: 20
  • ❌ "20" → seria texto.
  • ✅ 20 → correto.
  • ❌ True → valor lógico.
  • ❌ False → valor lógico.

Questão 3

Qual operador representa potência?

✅ Gabarito: D) **

Em Python, a potência é representada por dois asteriscos.

2 ** 3 Resultado: 8
2 × 2 × 2 = 8
  • ❌ * → multiplicação
  • ❌ / → divisão
  • ❌ % → resto da divisão
  • ✅ ** → potência
