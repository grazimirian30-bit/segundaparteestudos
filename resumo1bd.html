Conceitos do "Zero Absoluto" à Modelagem Profissional

🧱 1. O Zero Absoluto: De 0 e 1 à Informação

Tudo começa com o pulso elétrico. Para o computador, o dado é binário. A transformação ocorre assim:

DADO (Fato Bruto)
CAMPO (Significado)
REGISTRO (Objeto)
BANCO DE DADOS

Por que não usar apenas arquivos de texto? O material destaca que sistemas de arquivos comuns geram redundância (dados repetidos) e inconsistência (dados diferentes para a mesma coisa).

🛡️ 2. O SGBD: O Guardião dos Dados

O Sistema de Gerenciamento de Banco de Dados é o software que faz a ponte entre o usuário e os dados. Suas funções principais são:

Atomicidade Garante que uma operação complexa (como transferência bancária) ocorra inteira ou não ocorra nada.
Segurança Controla quem pode ver ou apagar cada informação.
Integridade Impede que dados inválidos (como idade negativa) sejam salvos.
Concorrência Permite que mil pessoas acessem o mesmo dado sem travar o sistema.

Tipos de Atributos (Glossário Visual)

  • Determinante: Identificador único (ID). É o círculo preenchido.
  • Composto: Se divide em outros (Ex: Endereço -> Rua, CEP).
  • Multivalorado: Pode ter vários valores (Ex: Telefone 1, Telefone 2). Representado por linha dupla.

🔄 4. O Fluxo de Criação (Do Cliente ao Banco)

Não se pula direto para o código. O processo profissional segue este workflow:

1. Modelo Descritivo

Entrevista e texto com os requisitos do negócio.

2. Modelo Conceitual

O desenho (DER). Foco na regra de negócio.

3. Modelo Lógico

Tabelas reais, PKs, FKs e tipos de dados (Int, Varchar).

🧬 5. Especialização: A Árvore de Decisão

Quando uma entidade tem subtipos (Ex: Pessoa -> Física ou Jurídica):

Sigla Significado Regra de Ouro
(t, d) Total Disjuntiva DEVE ser um dos filhos e APENAS um.
(p, c) Parcial Compartilhada Pode não ser nenhum, ou ser vários ao mesmo tempo.
